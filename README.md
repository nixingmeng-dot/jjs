# 墨笔 · 小说创作工作台

一个在本机运行的长篇小说写作工具：大纲、分卷、章节、人物、设定、伏笔一应俱全，可以接入任意大模型 API，并内置一套「去 AI 味」工具，让 AI 参与写出来的文字不像 AI 写的。

所有数据（作品、API Key）都只保存在本机的 `data/inkwell.db`（SQLite）里。

## Windows 一键使用（例如装到 D 盘）

1. 安装 [Node.js](https://nodejs.org/zh-cn/download)（LTS 版本，22 或更高），一路“下一步”即可。
2. 下载本项目的 ZIP，解压到你想放的位置，例如 `D:\inkwell`（路径里最好不要有空格）。
3. 双击文件夹里的 **`start.bat`**。

第一次启动会自动安装依赖（1~3 分钟，默认走国内 npm 镜像，失败会自动换源）并构建界面，之后每次双击几秒钟就会打开浏览器。使用期间保持那个黑色窗口开着，关掉窗口就退出了。

- 作品和 API Key 都在 `D:\inkwell\data` 文件夹里，**备份就是复制这个文件夹**。
- 想放到桌面：右键 `start.bat` → 发送到 → 桌面快捷方式。
- 更新：下载新版 ZIP，解压覆盖到同一个文件夹（`data` 文件夹会保留），再双击 `start.bat`，它会自动重新安装和构建。
- macOS / Linux 同样可以用 `npm run launch` 一键启动。

## 快速开始（开发者）

需要 Node.js 22 或更高版本。

```bash
npm install
npm run dev          # 开发模式：打开 http://localhost:5173
```

日常使用可以先构建再启动，只占一个端口：

```bash
npm run build
npm start            # 打开 http://127.0.0.1:8787
```

可选环境变量：

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | `8787` | 服务端口 |
| `HOST` | `127.0.0.1` | 监听地址。设为 `0.0.0.0` 可在局域网其他设备访问（注意 API Key 也会因此可被访问） |
| `INKWELL_DATA_DIR` | `./data` | 数据库目录 |

首次使用：进入「设置 → 模型服务」，选择服务商并填入 API Key，点「从服务商拉取模型列表」勾选模型，再点「测试连接」。

## 功能

**写作结构**
- 作品 → 分卷 → 章节，章节可拖拽排序、跨卷移动；「楔子」「番外」等不占章号
- 每章有细纲、摘要、备注；章节状态（草稿 / 修改中 / 完成）
- 总纲、卷纲、章节细纲逐层细化，AI 可分别生成总纲、规划分卷、批量规划章节细纲（生成后可勾选、编辑再添加）
- 人物卡（含「说话方式」「动机与恐惧」「人物弧光」等），AI 创建或完善人物
- 世界设定条目（地点、势力、力量体系……），伏笔追踪（埋设 / 回收章节、状态）

**编辑器**
- 自动保存、每 20 分钟自动留存历史版本，可预览和恢复；AI 整章改写前自动存档
- 全书搜索（Ctrl+K）、章内查找替换、一键排版（段首缩进）、明亮 / 护眼 / 夜间主题
- 正文字体可选黑体 / 宋体 / 楷体（宋体、楷体已内置，离线可用）
- 专注模式：深色沉浸界面，只亮当前段落，打字机式滚动，页边提示当前段落里的 AI 腔
- 字数统计、每日字数与目标、30 天字数图
- 导入 TXT（自动识别「第X卷 / 第X章」）、导出 TXT / Markdown / 完整备份

**AI 助手**
- 底部输入框：写一句要求回车即从光标处续写；选中文字时则按要求改写。Ctrl+Enter 直接续写（空章节会按细纲起草）
- 续写和起草的结果以浅色文字直接接在正文后面，Tab 接受、Esc 放弃，也可「换一个」或「去 AI 味」
- 选中文字后弹出浮动工具条：润色、扩写、精简、去 AI 味、增强画面感、打磨对白、加入感官细节、增强张力；改写结果在选区下方对照显示
- 右侧 AI 面板（顶栏「问 AI」或 Ctrl+J）：生成本章细纲 / 摘要、额外要求、AI 味检测报告
- 灵感（剧情走向、冲突、细节、起名）、编辑视角审稿、与熟悉全书资料的搭档对话
- 结果流式显示，支持推理模型的思考过程；写入正文后可 Ctrl+Z 撤销

AI 每次调用都会自动组装上下文：作品信息、文风设定与样本、总纲与卷纲、前几章摘要和上一章结尾、正文里出现的人物与设定、未回收的伏笔。

## 去 AI 味

从两个方向入手：

1. **生成时约束**：每次生成正文都会注入写作守则（具体细节、展示而非告知、长短句交错、段尾不升华、对白像真人、比喻少而准……）和高频套话禁用清单。强度可在设置中选择关闭 / 标准 / 严格。作品信息页可以填写**文风要求**和**文风样本**——贴一段你自己的文字，是让 AI 写得像你的最有效方法。
2. **生成后检测**：本地检测器（不消耗 token）按 10 类规则标出 AI 腔：神态套话（“嘴角勾起一抹弧度”）、空泛情绪词、段尾升华、模板化氛围描写、论文腔连接词、副词堆砌、直接告知情绪、油腻网文腔、AI 句式（“不是……而是……”），以及句长过于整齐、比喻 / 破折号过密、连续同字开头等统计特征，给出 0~100 的 AI 味指数，并可在正文中高亮、点击定位。检测结果可以一键交给模型做**针对性改写**；每段 AI 生成的结果也会自动评分，并可「再去 AI 味」。

自定义禁用词可以在设置（全局）和作品信息（单本）里添加。

## 支持的模型接口

| 接口协议 | 请求地址 | 适用 |
|---|---|---|
| OpenAI 兼容（Chat） | `{Base URL}/chat/completions` | OpenAI、DeepSeek、通义千问、Kimi、智谱 GLM、豆包、硅基流动、OpenRouter、Ollama 本地模型，以及任何兼容的中转服务 |
| OpenAI Responses | `{Base URL}/responses` | OpenAI 新接口，以及只提供 Responses 的中转服务；推理模型会显示思考摘要 |
| Anthropic（Messages） | `{Base URL}/v1/messages` | Claude 及兼容 Claude 格式的中转 |
| Gemini | `/v1beta/models/{模型}:streamGenerateContent` | Google Gemini |

四种协议都是流式输出，都支持拉取模型列表和测试连接。添加服务商时可以自由选择协议并填写任意 Base URL，所以中转服务只要选对协议即可。某个模型不支持 `temperature`、`reasoning` 等参数时，会自动去掉该参数重试。

可以同时添加多个服务商，在 AI 面板顶部随时切换模型。

## 项目结构

```
server/      Hono + better-sqlite3 后端：数据存储、导入导出、提示词组装、各家模型的流式调用
shared/      前后端共用：类型、中文文本工具、去 AI 味检测器、服务商预设
src/         React + Tailwind 前端
tests/       Vitest 测试（npm test）
```

常用命令：`npm test`、`npm run typecheck`、`npm run build`。
